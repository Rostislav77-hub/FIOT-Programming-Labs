# 📝 Lab 09: Logging Decorator with Configurable Log Levels

У цій лабораторній роботі реалізовано гнучку систему логування з використанням патерна Decorator. Оскільки у Vanilla JS нативні декоратори (`@`) не підтримуються без транспайлерів, патерн реалізований через **Функції Вищого Порядку (Higher-Order Functions)**.

## Архітектурні рішення

1. **Higher-Order Functions (HOF):** Декоратор `withLogging` обертає вихідну функцію, додаючи логіку до та після її виконання, при цьому зберігаючи прозорість (сигнатура та значення, що повертаються, не змінюються).
2. **Dependency Injection (DI):** Декоратор нічого не знає про те, куди і як писати логи. `Transport` (наприклад, `ConsoleTransport`) та `Formatter` (`JsonFormatter`, `SimpleFormatter`) передаються (інжектуються) зовні при налаштуванні.
3. **Sync / Async Transparency:** Декоратор автоматично розпізнає асинхронні функції (що повертають `Promise`). Він чекає на їх виконання (`resolve`/`reject`) для коректного виміру часу (duration).

## Ключові фічі

* 🎛 **Log Levels:** Підтримка рівнів `DEBUG`, `INFO`, `ERROR`. Рівень `ERROR` працює як "тихий страж" - логує лише винятки та провалені проміси, ігноруючи успішні виклики.
* ⏱ **Execution Profiling:** Автоматичний замір часу виконання функції в мілісекундах (з використанням `performance.now()`).
* 🧩 **Pluggable Formatters:** Легке перемикання між людиною текстом і структурованим JSON-форматом.
